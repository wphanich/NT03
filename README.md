# ระบบรับงานใหม่ ทีม นต03

โปรแกรมบันทึกงานรับใหม่ของทีม นต03 เปิด `index.html` ด้วยเว็บเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้งโปรแกรมเพิ่ม

## ข้อมูลที่บันทึก
| ช่อง | รายละเอียด |
|---|---|
| วัน เดือน ปี รับงาน | ค่าเริ่มต้นเป็นวันนี้ แสดงผลแบบ พ.ศ. |
| ประเภทการตรวจ | เลือกจากรายการหรือพิมพ์เพิ่มเองได้ |
| เลขประจำตัวผู้เสียภาษี | 13 หลัก ตรวจสอบหลักสุดท้าย (check digit) และเตือนเมื่อรับงานซ้ำ |
| ชื่อ | ชื่อบุคคล / นิติบุคคล |
| ที่อยู่ | แยกช่อง: **เลขที่**, อาคาร, ชั้น, ซอย, **จังหวัด**, **เขต/อำเภอ**, **แขวง/ตำบล**, รหัสไปรษณีย์ (ตัวหนา = บังคับกรอก) — เลือกจังหวัดแล้วจะแสดงเขต/อำเภอ และแขวง/ตำบล ให้เลือกต่อ พร้อมเติมรหัสไปรษณีย์ให้อัตโนมัติ |
| จำนวนเงินคืนภาษี | บาท ทศนิยม 2 ตำแหน่ง |
| ทีม | ค่าเริ่มต้น `นต03` |
| หมายเหตุ | |

## ความสามารถ
- เพิ่ม / แก้ไข / ลบ รายการ
- ค้นหา และกรองตามประเภทการตรวจ ทีม ช่วงวันที่ พร้อมสรุปจำนวนรายและยอดเงินคืนรวม
- เรียงลำดับโดยคลิกหัวตาราง
- ส่งออกเป็น CSV เปิดด้วย Excel ได้ (ที่อยู่แยกคอลัมน์ + ที่อยู่เต็ม) (ภาษาไทยไม่เพี้ยน เลข 0 นำหน้าไม่หาย)
- พิมพ์รายงาน
- สำรองข้อมูล / นำเข้าข้อมูลสำรอง (JSON)

## วิธีใช้
ดับเบิลคลิกเปิด `index.html` ด้วย Chrome หรือ Edge

ต้องวางไฟล์ `thai-address.js` (ข้อมูลจังหวัด/เขต/แขวง) ไว้ในโฟลเดอร์เดียวกับ `index.html`
หากไม่มีไฟล์นี้ ช่องจังหวัด/เขต/แขวง จะเปลี่ยนเป็นช่องพิมพ์เองแทน

### ข้อมูลจังหวัด/เขต/แขวง
ที่มา: [kongvut/thai-province-data](https://github.com/kongvut/thai-province-data) (MIT License)
— 77 จังหวัด, 930 เขต/อำเภอ, 7,436 แขวง/ตำบล หากต้องการอัปเดตข้อมูล:

```bash
git clone --depth 1 https://github.com/kongvut/thai-province-data.git
python3 scripts/build_thai_address.py thai-province-data/api/latest/province_with_district_and_sub_district.json
```

> **หมายเหตุ:** ข้อมูลถูกเก็บในเบราว์เซอร์ของเครื่องที่ใช้งาน (localStorage)
> หากล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่อง ข้อมูลจะไม่ตามไปด้วย
> ควรกด **"สำรองข้อมูล (JSON)"** เป็นประจำ และใช้ **"นำเข้าข้อมูลสำรอง"** เพื่อย้ายข้อมูลไปเครื่องอื่น
