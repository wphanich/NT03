# ระบบรับงานใหม่ ทีม นต03 (ออนไลน์ด้วย Firebase)

ระบบบันทึกงานรับใหม่ของทีม นต03 ใช้งานผ่านเว็บเบราว์เซอร์ ข้อมูลเก็บบน Firebase (Cloud Firestore)
ทุกคนในทีมเห็นข้อมูลชุดเดียวกันแบบเรียลไทม์ ต้องเข้าสู่ระบบก่อนใช้งาน

## ข้อมูลที่บันทึก
| ช่อง | รายละเอียด |
|---|---|
| วัน เดือน ปี รับงาน | ค่าเริ่มต้นเป็นวันนี้ แสดงผลแบบ พ.ศ. |
| ประเภทการตรวจ | เลือกจากรายการหรือพิมพ์เพิ่มเองได้ |
| เลขประจำตัวผู้เสียภาษี | 13 หลัก ตรวจสอบหลักสุดท้าย (check digit) และเตือนเมื่อรับงานซ้ำ |
| ชื่อ | ชื่อบุคคล / นิติบุคคล |
| ที่อยู่ | แยกช่อง: **เลขที่**, อาคาร, ชั้น, ซอย, ถนน, **จังหวัด**, **เขต/อำเภอ**, **แขวง/ตำบล**, รหัสไปรษณีย์ (ตัวหนา = บังคับกรอก) — เลือกจังหวัดแล้วจะแสดงเขต/อำเภอ และแขวง/ตำบล ให้เลือกต่อ พร้อมเติมรหัสไปรษณีย์ให้อัตโนมัติ |
| จำนวนเงินคืนภาษี | บาท ทศนิยม 2 ตำแหน่ง |
| ทีม | ค่าเริ่มต้น `นต03` |
| หมายเหตุ | |

ระบบบันทึกให้อัตโนมัติว่า **ใครบันทึก / ใครแก้ไขล่าสุด และเมื่อไร** (เอาเมาส์ชี้ที่ชื่อในตารางเพื่อดู)

## ความสามารถ
- เข้าสู่ระบบด้วยอีเมล/รหัสผ่าน, ลืมรหัสผ่าน (ส่งลิงก์ทางอีเมล)
- เพิ่ม / แก้ไข / ลบ รายการ — เครื่องอื่นเห็นการเปลี่ยนแปลงทันที
- ค้นหา และกรองตามประเภทการตรวจ ทีม ช่วงวันที่ พร้อมสรุปจำนวนรายและยอดเงินคืนรวม
- เรียงลำดับโดยคลิกหัวตาราง
- ส่งออกเป็น CSV เปิดด้วย Excel ได้ (ภาษาไทยไม่เพี้ยน เลข 0 นำหน้าไม่หาย)
- พิมพ์รายงาน
- สำรองข้อมูล (JSON) และนำเข้าข้อมูลจากไฟล์สำรอง (เพิ่มเฉพาะรายการที่ยังไม่มี ไม่ลบของเดิม)

## ความปลอดภัย
- ต้องเข้าสู่ระบบ **และ** ได้รับสิทธิ์จากผู้ดูแล (มีชื่ออยู่ในคอลเลกชัน `members`) จึงจะเห็นหรือแก้ไขข้อมูลได้
- กฎใน `firestore.rules` ตรวจรูปแบบข้อมูลทุกครั้งที่บันทึก (เช่น เลขผู้เสียภาษีต้อง 13 หลัก, จำนวนเงินต้องเป็นตัวเลข ≥ 0)
  และป้องกันการปลอมชื่อผู้บันทึก/เวลาที่บันทึก
- ผู้ใช้เพิ่มสิทธิ์ให้ตัวเองไม่ได้ — เพิ่มได้จาก Firebase Console เท่านั้น

## การติดตั้ง (ผู้ดูแลระบบ ทำครั้งเดียว)

ต้องมี: บัญชี Google และ [Node.js](https://nodejs.org/) (สำหรับคำสั่ง `firebase`)

### 1. สร้างโปรเจกต์ Firebase
1. เข้า <https://console.firebase.google.com> → **Add project** ตั้งชื่อ เช่น `nt03-jobs`
2. **Build → Authentication → Get started → Sign-in method** → เปิด **Email/Password**
3. **Build → Firestore Database → Create database** → เลือก location `asia-southeast1 (Singapore)` → เลือก **Production mode**
4. **Project settings (รูปเฟือง) → General → Your apps** → กดไอคอน **`</>`** (Web) ตั้งชื่อแอป → จะได้ค่า `firebaseConfig`

### 2. ใส่ค่าการเชื่อมต่อ
- คัดลอกค่า `firebaseConfig` จากข้อ 1.4 ไปแทนค่าในไฟล์ `public/firebase-config.js`
- แก้ `YOUR_PROJECT_ID` ในไฟล์ `.firebaserc` เป็น Project ID ของคุณ

### 3. อัปโหลดขึ้นระบบ
```bash
npm install -g firebase-tools
firebase login
firebase deploy
```
เสร็จแล้วจะได้ลิงก์ใช้งาน เช่น `https://nt03-jobs.web.app`

### 4. เพิ่มผู้ใช้งาน (ทำทุกครั้งที่มีสมาชิกใหม่)
1. **Authentication → Users → Add user** ใส่อีเมลและรหัสผ่านเริ่มต้น → คัดลอกค่า **User UID**
2. **Firestore Database → Start collection** (ครั้งแรก) หรือเข้าคอลเลกชัน `members` → **Add document**
   - Collection ID: `members`
   - Document ID: วาง **User UID** จากข้อ 1
   - เพิ่ม field เช่น `email` (string) = อีเมลของผู้ใช้ (เพื่อให้ดูง่าย)
3. แจ้งผู้ใช้ให้เข้าสู่ระบบ และเปลี่ยนรหัสผ่านด้วยปุ่ม "ลืมรหัสผ่าน"

> ถ้าผู้ใช้เข้าสู่ระบบแล้วขึ้นว่า "ยังไม่ได้รับสิทธิ์" หน้าจอจะแสดง UID ให้ — นำไปทำข้อ 4.2
> ยกเลิกสิทธิ์: ลบเอกสารของผู้ใช้ใน `members` (และ Disable บัญชีใน Authentication)

### 5. ย้ายข้อมูลจากเวอร์ชันเดิม (ถ้ามี)
1. เปิด `index.html` เวอร์ชันเดิมในเครื่องที่ใช้อยู่ → กด **"สำรองข้อมูล (JSON)"**
2. เข้าระบบออนไลน์ → กด **"นำเข้าข้อมูลจากไฟล์สำรอง"** → เลือกไฟล์ที่ได้

## โครงสร้างไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `public/index.html` | หน้าจอ |
| `public/app.js` | การทำงานของระบบ |
| `public/firebase-config.js` | ค่าการเชื่อมต่อ Firebase (แก้ตามข้อ 2) |
| `public/thai-address.js` | ข้อมูลจังหวัด/เขต/แขวง/รหัสไปรษณีย์ |
| `firestore.rules` | กฎความปลอดภัยของฐานข้อมูล |
| `firebase.json`, `.firebaserc` | การตั้งค่า Firebase Hosting / โปรเจกต์ |

### ทดสอบในเครื่องด้วย Firebase Emulator
```bash
firebase emulators:start --project demo-nt03
```
แล้วเปิด `http://localhost:5000/?emulator` (ต้องใส่ค่าใน `firebase-config.js` ที่มี `projectId: "demo-nt03"`)
สร้างผู้ใช้และเอกสาร `members` ได้ที่ Emulator UI `http://localhost:4000`
